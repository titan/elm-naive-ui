## Peer wiring

- Button: `Button.defaults{ variant=Quaternary, kind=buttonKindOf status, icon=… }` +
  NEW additive seam `Button.Options.varOverrides : List (String,String)` (default []) applied
  replace-in-place (key exists → value swapped, order kept; new keys appended) inside
  `Button.cssVars`. Upload passes `[("--n-padding","0 3px"),("--n-height","24px"),("--n-icon-size","18px")]`
  = upstream builtinThemeOverrides (buttonThemeOverrides const, UploadFile.tsx:21-25).
  Default [] = byte-identical for every existing caller (transfer's attributes precedent).
- Progress: `Progress.view theme { defaults | type_=Line, showIndicator=False, percentage=…, status=…, height=Just 2 } []`
  (confirm exact field names at feat time).
- Image (image-card thumb): `{ defaults | src=mergedThumbnailUrl, previewSrc=file.url, alt=Just file.name }`.
- ImageGroup (image-card list): pass-through imageGroupOptions; NImageGroup adds its own container.
- Icons: 7 + 2 glyphs as private svg elements (Transfer SearchIcon/CloseIcon precedent);
  baseIcon wrapper = `i.n-base-icon`.

## Divergences to docstring in NUI/Upload.elm (accepted edges)

1. `file : File` dropped from FileInfo (Elm has no File); thumbnail async resolution
   (createImageDataUrl/objectURL) is caller-side — caller writes resolved URL into
   thumbnailUrl; environmentSupportFile ≡ true.
2. XHR + customRequest + beforeUpload/finish/error callbacks + directory-dnd entry traversal
   = host ports; module exposes the pure transitions only.
3. draggerInside explicit (no slot introspection); abstract Teleport-to-body = caller places
   the returned Fragment.
4. onRemove carries id, not (file,fileList,index); RenderTrigger options-object slot dropped
   (caller wires its own drag/click msgs directly).
5. RTL dropped (rtlEnabled default false; --rtl class + rtl.cssr omitted — house precedent).
6. scheduleDoChange/nextTick serialization n/a (synchronous Elm).
7. defaultUpload / auto-submit after addition = caller's responsibility (filesToSubmit is the
   selection rule, nothing auto-fires).
8. `value=''` reset of the input after change = DOM-cmd side (host).
